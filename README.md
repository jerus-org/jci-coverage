# jci-coverage

Source-based Rust code coverage ([`cargo-llvm-cov`](https://crates.io/crates/cargo-llvm-cov))
with upload to [OtterWise](https://getotterwise.com) for code quality reporting.

[![License](https://img.shields.io/badge/license-MIT%20OR%20Apache--2.0-blue.svg)](#license)

This is a Cargo workspace. The published crate lives in
[`crates/jci-coverage`](crates/jci-coverage) — see its
[README](crates/jci-coverage/README.md) for installation, usage, and the runtime
prerequisites.

> **Status:** early scaffold (0.0.x, pre-pre-release). The CLI surface (`report` and
> `upload`) is in place; subcommand behaviour is landing incrementally. See
> [ROADMAP.md](ROADMAP.md) for the phased plan.

## Why

- `report` orchestrates `cargo-llvm-cov` to generate a coverage report
  (`coverage/lcov.info`), aiming to be a drop-in replacement for
  `circleci-toolkit`'s `code_coverage` job.
- `upload` is a standalone, language-agnostic subcommand: it posts a coverage file to
  OtterWise. It does not require `report`, Rust, or `cargo-llvm-cov` — a non-Rust
  project can use it on its own, against a coverage report generated by whatever means
  it already uses.

## Development

```bash
just test        # clippy + check + doc + tests

just msrv        # verify the declared MSRV builds

just licenses    # regenerate THIRD-PARTY-LICENSES.md (cargo-about)
```
